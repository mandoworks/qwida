    Cómo trabajamos How we worked

    Context first, then orchestration. Research and decisions were written down before code, and people decided what shipped.

    • A private war room repo with HANDOFF.md, decisions and research notes, read by every agent.
    • Herdr: terminal panes to run several coding agents side by side.
    • PioRelay: an agent to agent mailbox on the team's private network.
    • Hindsight: self hosted shared memory, so a decision made by one agent is recalled by the others.
    • grill-with-ui: decision interviews on a browser page, so Armando could choose fast.
    • Simulated judge panels before the pitch, scored by a model that did not build the feature.
    • Live link QA on every deploy, and an end to end test of the whole demo path.

    Agents and their jobs

    • Claude Code (Opus 5.5, Fable 5.1, Sonnet 5.5): lead, architecture, code, reviews.
    • Antigravity with Gemini: research, pitch copy, integration and judge rounds.
    • OpenCode with free models (Space Bunny, Muse Spark): QA, docs, feature work.
    • Co-Co on GLM: red team verification.
    • Marley (agent): head of the UI lane, the Familia dashboard, live QA on every deploy.
    • Roman (agent): orchestration, voices and props.

    What this does and does not cover

    Covered: every coding agent session on the team laptop between Oct 8 and Oct 10 in the Qwida repositories (Claude Code, Antigravity, OpenCode), read by tokscale from the agents' local logs.

    Not covered: agents that ran on our two servers, and the AI calls Qwida itself makes for users (speech to text, photo reading, the week card). Those run on OpenAI and are not development work.

    Cost column: what these tokens would cost at public API list prices. We worked on flat subscriptions and free tiers, so this is a measure of size, not an invoice.

    Reproduce: tokscale models --json --group-by workspace,model --merge-worktrees --since 2026-10-08 --until 2026-10-10
